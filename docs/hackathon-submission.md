## Description draft

Porti is an anime-inspired NEAR AI Cloud companion that connects token research, wallet monitoring and reviewed financial workflows. Users can investigate tokens, follow sampled top traders, receive Telegram observations and prepare payments to verified platform usernames. The agent opens purchase, staking and NEAR Intents swap reviews; users retain wallet signing authority. Server-side checks bind sender, amount, output network, recipient, slippage and refund destination before a wallet request. Porti separates model suggestions, signed actions and observed outcomes, and reports missing provider data honestly. Our goal is a friendly interface for using NEAR without hiding transaction details or giving an AI unrestricted wallet access.

Only add claims of live X linking, card purchases or cross-chain settlement after owner acceptance succeeds. Do not claim all NEAR token coverage, audited security, end-to-end encrypted chats, autonomous custody, perps trading or a guaranteed rug probability.
